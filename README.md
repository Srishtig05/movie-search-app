# 🎬 Movie Finder

A responsive movie search web application built using HTML, CSS, and JavaScript. The application uses the TMDB API to search for movies and display trending and upcoming movies with their posters, release years, and ratings.

## 🚀 Live Demo

Coming soon.

## ✨ Features

* 🔍 Search for movies using the TMDB API
* 🔥 Browse trending movies
* 📅 Browse upcoming movies
* 🎬 Display movie posters and information
* ⭐ Display movie ratings
* 📱 Responsive user interface
* ⏳ Loading states while fetching data
* ❌ Error handling for failed API requests
* ⚠️ Handles cases when no movies are found
* 🔄 Fetches movie data dynamically from an external API

## 🔌 API

Movie data is provided by [The Movie Database (TMDB)](https://www.themoviedb.org/).

The application uses TMDB endpoints for:

* Movie search
* Trending movies
* Upcoming movies

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Srishtig05/movie-search-app.git
```

2. Open the project folder.

3. Add your TMDB API token to `script.js`.

4. Open `index.html` in a browser or use the VS Code Live Server extension.

> **Note:** The API token is not included in this repository.
